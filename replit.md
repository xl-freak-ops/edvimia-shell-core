# Edvimia — AI School Operating System

A TanStack Start (React + TypeScript) web application — an AI-powered operating system for primary and secondary schools. Built with Lovable and imported to Replit for continued development.

## Stack

- **Framework**: TanStack Start (SSR) + TanStack Router (file-based routing)
- **Auth & Database**: Supabase
- **UI**: Tailwind CSS v4 + shadcn/ui (Radix UI)
- **Package manager**: Bun
- **Build tool**: Vite (via `@lovable.dev/vite-tanstack-config`)

## Running the app

```bash
bun run dev   # starts dev server on port 5000
```

The workflow "Start application" is configured to run `bun run dev` automatically.

## Environment variables

Set in Replit's shared environment (sourced from `.env`):

| Key | Description |
|-----|-------------|
| `VITE_SUPABASE_URL` | Supabase project URL |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | Supabase anon/publishable key |
| `SUPABASE_PROJECT_ID` | Supabase project ID |

## Project structure

```
src/
  routes/         # File-based routes (TanStack Router)
    __root.tsx    # App shell — wraps every page
    index.tsx     # Root redirect (auth-aware)
    welcome.tsx   # Landing page
    login.tsx / signup.tsx / ...
    _authenticated/  # Protected routes
  components/     # Shared UI components (shadcn/ui)
  lib/            # Auth, utilities
  integrations/   # Supabase client & types
supabase/
  migrations/     # Database migrations
```
